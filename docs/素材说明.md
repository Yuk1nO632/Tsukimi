# 海报与资料来源

更新日期：2026-10-24。

资料来自 Bangumi 公开 API，标题、集数、简介、标签、首播日期和评分保存在 project/frontend/lib/catalog.generated.js。每条记录包含 sourceUrl 和 coverSource，可追溯原始条目及封面。

真实海报下载至 project/frontend/public/covers，使用 npm.cmd run sync:catalog 更新；页面平时读取本地快照。
