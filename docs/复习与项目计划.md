## 第一版边界与完成标准

- 首页与详情使用联网资料和本地精选；进入播放页自动匹配，必要时确认一次并记住来源，不全量抓取或镜像外部番剧库。
- 优先 Windows Chrome/Edge 与基础手机布局，继续只接稀饭单源；未匹配或来源失效时仍可查看与收藏。
- 浏览器直接连接来源 CDN；若将来需要转发视频，再单独评估流量、成本与实现范围。
- 第一版沿用匿名会话；账号、跨设备同步、多源规则、弹幕、下载、BT 和超分辨率暂不加入。
- Cookie 清除、过期或更换浏览器后不保证找回原匿名记录；SQLite 不保存视频文件。
- PostgreSQL 和一键发布是后续课程练习，不阻塞当前 SQLite 版的收藏、播放与续播闭环。

第一版主流程为：发现番剧 → 详情 → 收藏 → 匹配来源 → 选集播放 → 保存进度 → 继续观看。

完成时，应能实际完成上述流程；刷新和服务重启后数据保留；失败有反馈；可依照文档启动、部署、备份与恢复，并解释主要数据流。
